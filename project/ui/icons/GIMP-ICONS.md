# Icon provenance

The following icons are adapted from the GIMP 3 "Default" (symbolic) icon
theme (https://gitlab.gnome.org/GNOME/gimp), licensed under the GNU GPL v3
or later. They were rescaled to render at 24 px and recolored to plain
white so the editor theme can tint them:

smooth.svg (gimp-tool-blur), ramp.svg (gimp-tool-gradient),
paint.svg (gimp-tool-paintbrush), clone.svg (gimp-tool-clone),
select.svg (gimp-tool-move), qsel.svg (gimp-tool-ellipse-select),
rsel.svg (gimp-tool-rect-select), wand.svg (gimp-tool-fuzzy-select),
noise.svg (gimp-tool-warp), grid.svg (gimp-grid),
slope.svg (gimp-landscape).

qsel is ellipse-select, not free-select.

The remaining icons in this directory are original to this project, drawn
to match that style.
